This repository contains all my practice code, notebooks, and projects completed during DevTown's Machine Learning Mastery Bootcamp — a free, beginner-friendly, 5-day live bootcamp covering core ML concepts, model comparison, and end-to-end project building.

📅 Bootcamp Schedule & Day-wise Descriptions

🗓️ Day 1 – Understanding Core Machine Learning Concepts
Topics Covered:

What is Machine Learning and why it matters
Types of ML: Supervised, Unsupervised, and Reinforcement Learning
Key ML terminology: features, labels, training, testing, overfitting
Introduction to the ML workflow (data → model → prediction)
Setting up the Python environment (NumPy, Pandas, Scikit-learn)

What I practiced:
Hands-on exploration of basic ML concepts with Python. Loaded real datasets and ran simple experiments to understand how a machine "learns" from data.

🗓️ Day 2 – Comparing Popular Supervised Learning Models
Topics Covered:

Linear Regression vs Logistic Regression
Decision Trees and Random Forests
Support Vector Machines (SVM)
K-Nearest Neighbors (KNN)
How to choose the right model for a given problem

What I practiced:
Implemented and compared multiple supervised learning models on the same dataset. Analyzed trade-offs between model complexity, accuracy, and interpretability.

🗓️ Day 3 – Discovering Patterns with Unsupervised Learning
Topics Covered:

What is Unsupervised Learning and when to use it
Clustering algorithms: K-Means, Hierarchical Clustering
Dimensionality Reduction: PCA (Principal Component Analysis)
Visualizing high-dimensional data
Real-world use cases (customer segmentation, anomaly detection)

What I practiced:
Applied clustering techniques to unlabeled datasets to discover hidden patterns and groups. Used PCA to reduce dimensions and visualize data in 2D.

🗓️ Day 4 – Evaluating Models Using Performance Metrics
Topics Covered:

Why accuracy alone isn't enough
Classification metrics: Precision, Recall, F1-Score, Confusion Matrix
Regression metrics: MAE, MSE, RMSE, R² Score
ROC Curve and AUC
Cross-validation and avoiding overfitting
Bias-variance tradeoff

What I practiced:
Evaluated trained models using multiple metrics to get a complete picture of performance. Learned how to tune models and validate them properly using cross-validation.

🗓️ Day 5 – Building End-to-End Machine Learning Projects
Topics Covered:

The full ML pipeline: problem definition → data collection → preprocessing → modeling → evaluation → deployment
Feature engineering and handling missing data
Model saving and loading (Pickle / Joblib)
Introduction to deploying ML models
Project walkthrough and best practices

What I practiced:
Built a complete, end-to-end ML project from scratch — from raw data to a trained, evaluated, and saved model. Applied everything learned across the 5 days into one cohesive project.

🛠️ Tech Stack

Language: Python 3.x
Libraries: NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
Environment: Jupyter Notebook / Google Colab
